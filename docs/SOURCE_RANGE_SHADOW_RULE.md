# Frozen Shadow Rule: Unique Method in Oversized Full-File Proposals

This rule is experimental and is recorded before the six development outcomes are measured. It is not a production selector change.

For a production `ContextBuilder._select_ranges` result, compute the same merged ranges and the same 75%-of-file promotion test as production. Consider narrowing **only** when that result would be a full-file proposal in balanced mode, the redacted full-file estimate is at least 1,000 local tokens, the file is an existing relevance candidate, the file is not a test, and no explicit/trace path or required range demands full-file delivery.

Collect distinct terms of at least six characters from that candidate's existing `symbol_term`, `source_term`, and `import_term` signals. For each indexed Python function or method, count how many such terms appear in its source body or qualified symbol name using the existing relevance tokenizer. Narrow only if one function/method has at least two distinct hits and strictly more hits than every other function/method. The narrow proposal contains that symbol's indexed line span plus the balanced context lines, its class header if applicable, and import lines referenced in its body. Use production range merging, then decline the substitution if the result would cover at least 75% of the file or its redacted estimated token cost is not lower. All other cases retain the exact production proposal.

The 1,000-token threshold identifies proposals costing at least one sixth of the unchanged 6,000-token budget; it is not tuned per task. Query evidence comes only from production candidate signals and indexed source symbols. No task IDs, reference paths, cited lines, or answer locations enter the rule. Ranking, candidate cap/order/scores, imports/tests graph, affinity, allocation, redaction, budget, and locator behavior are inherited unchanged.

Acceptance for further offline research requires a strict increase in complete development core-area range coverage, no lost previously complete core area or cited test range, retention of N01 completeness and E01's full explicit anchor, no budget/integrity/safety regression, and actual delivered-range evidence explaining the gain. Otherwise reject. Sensitivity is reported both with all 16 proposed core areas and with N01 `ownership` and G02 `range_selection` excluded as previously disputed, without choosing the favorable interpretation afterward. Reserved labels are not evaluated.
