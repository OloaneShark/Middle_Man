# Middle_Man repository workflow

For repository-wide questions or substantial changes, prefer the local `middle-man` MCP server when available. Check `middleman_session_handoff` or `middleman_project_state` for orientation, use `middleman_find_context` to locate relevant files, then request a bounded `middleman_context_pack` (`safe` first). Expand only when the selected excerpts lack necessary detail. Use `middleman_changed_context` for Git awareness and `middleman_compact_output` for large tool output.

Native file reads, search, Git, and tests remain available. Use them when MCP is unavailable, stale, incomplete, or exact full source is needed. Skip MCP for trivial known-file edits. Never infer intent or test results from repository metadata; verify them directly. Middle_Man token figures are local estimates, not Codex usage or billing.
