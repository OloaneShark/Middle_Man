# Middle_Man repository workflow

For fresh scoped work, call `middleman_context` directly when the Codex-core MCP server is available. Pass the concrete engineering request with its behaviors or symbols, not a generic inspection query. For continuation, use `middleman_session_handoff`. Use `middleman_project_state` only for broad orientation, `middleman_expand_context` when excerpts are insufficient, and `middleman_compact_output` for large tool output. Do not automatically call handoff or project state for fresh work.

Native search, reads, Git, and tests remain valid when MCP is unavailable, stale, incomplete, or exact source is needed. Skip MCP for trivial known-file work. Verify behavior directly; repository metadata is not proof of intent or test results. Middle_Man token figures are local estimates, not Codex usage.
