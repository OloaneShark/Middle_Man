# Middle_Man repository workflow

For fresh scoped work, call `middleman_context` with the concrete request and relevant behaviors or symbols. For continuation, use `middleman_session_handoff`; use `middleman_project_state` for broad orientation and `middleman_compact_output` for large output.

When part of a relevant file was delivered, prefer `middleman_expand_context` for missing lines before a whole-file reread. Native reads, Git, and tests remain valid for exact or stale source and editing. Skip MCP for trivial known-file work. Verify behavior directly. Middle_Man token figures are local estimates, not Codex usage.
